# S07 个体基线迁移算法 v1

## 目的
用模拟纵向回放验证“什么时候开始更多相信个人数据，以及缺失/异常数据是否会把基线带偏”。

## 权重
`w_n = min(0.8, n / (n + 8))`

- `n`：通过质量控制的个人有效观测数；
- 个人权重最大为 0.8，不会快速变成 1；
- 其余权重保留给群体参考。

## 个人参考
使用有效个人观测的中位数，降低单次极端值影响。

## 异常值
个人历史达到 5 条后，使用中位数 + MAD 的鲁棒规则检测极端值；
阈值同时设置工程下限，避免早期样本波动导致过度拒绝。

## 缺失数据
缺失观测不更新个人历史，不改变 baseline。

## 三阶段
- population_reference
- mixed_baseline
- personal_dominant

注意：以上均为工程验证参数，不是医学阈值或临床结论。
