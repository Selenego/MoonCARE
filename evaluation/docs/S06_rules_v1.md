# S06 冷启动规则 v1

## 输入
- `ema_distress`: 0-5，可缺失
- `physiological_deviation`: 上游产生的“是否偏离”布尔信号，可缺失
- `cycle_phase`: 周期阶段，可缺失
- `history_count`: 个人历史有效观测数量

## 决策原则
1. 不在本模块写死临床生理阈值；
2. EMA >= 4 时仅标记“较高主观困扰”，不做诊断；
3. 上游存在 physiological_deviation 时仅标记“需要关注的相对状态”；
4. 有效输入不足 2 类时进入降级状态；
5. 冷启动置信度只跟数据完整度变化：0/1/2/3 类信号对应 0.20/0.35/0.50/0.65；
6. 冷启动阶段不允许宣称形成稳定个人基线。

## 边界
这是工程规则原型，用于 S06 行为验证，尚未全面接入生产主链。
