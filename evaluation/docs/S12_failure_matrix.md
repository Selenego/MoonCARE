# S12 故障注入矩阵

| 故障 | 预期行为 |
|---|---|
| LLM 超时（普通支持） | 返回非空本地降级回复 |
| LLM 超时（行动请求） | 返回具体下一步，不空白、不崩溃 |
| LLM 超时（危机） | Safety 文案优先 |
| 知识链异常 | 返回谨慎知识降级回复 |
| RAG 空结果 | KnowledgeAgent 返回谨慎 fallback |
| 周期信息缺失 | 明确标记未知/缺失，不能假设处于某周期阶段 |
| 传感器数据缺失 | 降级为空字典并继续运行 |

`Fake Success Count` 用于检查故障后是否出现“操作已完成/已保存”等虚假成功表述。
