# MoonCARE S14 隐私与删除能力源码审计

本轮先做**源码级**隐私、权限和删除能力基线，目的是快速回答：

- AgentTrace 是否尽量避免记录原始消息；
- 日记读取/删除是否带用户所有权过滤；
- 是否存在整账号删除入口；
- 是否存在会话删除入口；
- `.env` 是否被 Git 跟踪；
- 模型层有哪些敏感数据类别可进入数据字典。

运行：

```powershell
.\.venv\Scripts\python.exe .\evaluation\scripts\eval_privacy_audit.py
```

结果仅可写成“源码级隐私/删除能力审计”，不能替代完整隐私合规测试，也不能替代真实
“采集 → 存储 → 读取 → 删除 → 残留验证”。
